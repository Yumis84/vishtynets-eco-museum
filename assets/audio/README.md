# Аудиогид — структура аудио

Все аудиодорожки хранятся в `assets/audio/`.

## Рассказчики

- `alexey/` — оригинальная авторская озвучка Алексея.
- `grok/` — AI-версия; добавляется только после появления реальных аудиофайлов.

## Правило именования

Для каждой версии используются одинаковые ID дорожек:

- `h1-01` … `h1-07` — Зал 1
- `h2-01` … `h2-07` — Зал 2

Имена файлов внутри разных папок рассказчиков должны совпадать. Плеер меняет только базовую папку рассказчика.
