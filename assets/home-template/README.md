# Утверждённый шаблон главной страницы · v1 · 20.10.2026

**Статус:** утверждён пользователем как визуальный ориентир. Не перерисовывать и не менять концепцию без согласования.

## Как выглядит главная

Мобильная версия: кремовая шапка с названием и круглым меню; фотография Роминтской пущи на всю ширину под шапкой; белый крупный заголовок «Место, где природа хранит память»; подзаголовок; 4 светлые карточки «Исследовать», «Карта», «Статьи», «Аудиогид» в сетке 2×2; ниже «Начните исследование» с горизонтальной прокруткой фотообложек, белыми подписями и тёмным градиентом; закреплённое нижнее меню. Цвета: лесной зелёный, кремовый, тёплый белый.

Компьютерная версия: отдельная адаптивная компоновка в `home-desktop-reference.css`. Не применять мобильные правила к компьютеру.

## Где исходники

- `index.html`: настоящая структура сайта
- `home-mobile-approved.css`: утверждённый мобильный стиль
- `home-desktop-reference.css`: десктопные правила
- `app.js`: реальные карточки и переходы
- `assets/home-template/photo-sources.json`: проверяемый список источников
- `assets/home-template/originals/`: локальные копии архивных фотографий (добавляются workflow `home-template-assets.yml`)

**Важно:** макет-картинка из диалога ChatGPT не является файлом в репозитории. Этот каталог содержит воспроизводимый HTML/CSS-шаблон и оригинальные фото, а не выданный за код PNG-макет. Если потребуется хранить сам PNG, его нужно отдельно загрузить в `assets/home-template/references/`.

## Приёмка

1. Открыть сайт на ширинах 390, 768, 1280, 1440.
2. Убедиться, что главная фотография **загружается** и видна за заголовком.
3. Убедиться, что «Начните исследование» показывает изображения именно соответствующих мест.
4. Не изменять без задачи карту, статьи, аудиогид, нижнее меню.
5. Проверить реальные скриншоты браузера до слияния в `main`.
