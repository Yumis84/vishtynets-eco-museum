# Библиотека тематических обложек Виштынецкого экомузея

Единая коллекция обложек **навигационных карточек** разделов и категорий сайта.

## Принцип
- Каждая категория имеет собственный сюжет; повторять одну фотографию в разных карточках нельзя.
- Общий художественный язык: «Иллюстрированный атлас Виштынецкого края», природная палитра, тонкая графика, лёгкая фактура бумаги.
- Изображение не содержит текста: заголовок и описание выводятся HTML, чтобы оставаться доступными и переводимыми.
- Для новых категорий сначала добавить запись в manifest.json, затем создать обложку по style-guide.md.
- Исторические фотографии внутри статей **не заменять**.
- До согласования и проверки авторских прав изображения не публиковать на действующем сайте.

## Каталог
- museum-history/
- nature/
- routes/
- museum-of-time/
- accommodation/
- biodiversity/
- library/
- research/
- templates/

Для каждой категории: cover.webp (производственный файл после утверждения), source/ (редактируемые исходники при наличии), alt-текст в manifest.json.

Текущий статус: **структура библиотеки и художественное направление предложены, изображения ещё не утверждены**.
