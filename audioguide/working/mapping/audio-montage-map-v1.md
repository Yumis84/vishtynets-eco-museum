# Аудиогид — монтажная карта v1

Статус: подготовка монтажа без выдуманных таймкодов.

## Исходники

В `source/audio/original/` находятся пять исходных MP3. Они являются архивом и не изменяются.

| Файл | Назначение |
|---|---|
| `1.mp3` | исходная запись, часть 1 |
| `2.mp3` | исходная запись, часть 2 |
| `3.mp3` | исходная запись, часть 3 |
| `4.mp3` | исходная запись, часть 4 |
| `5.mp3` | исходная запись, часть 5 |

Точные границы треков определяются только после прослушивания исходников. Таймкоды заранее не задаются.

## Для каждого трека определить при монтаже

`track_id → source_audio → start → end → лишнее удалить → raw-cut → обработка → final`

## Что удаляем из рабочей версии

- посторонние разговоры с посетителями;
- вопросы и ответы группы, если они не являются частью экскурсионного текста;
- повторы и оговорки, не нужные для самостоятельного аудиогида;
- длинные неестественные паузы;
- технические шумы и явные помехи, если их можно убрать без повреждения голоса;
- фрагменты, не относящиеся к конкретному самостоятельному рассказу.

Не удалять автоматически естественные паузы, интонацию и живую манеру речи Алексея.

## Обработка финальных треков

1. Сначала сделать точный raw-cut из оригинала.
2. Затем очистить шум и гул.
3. При необходимости применить мягкое удаление лишних пауз.
4. Выровнять громкость между всеми треками.
5. Проверить отсутствие обрезанных согласных/слов в местах склейки.
6. Экспортировать финальный MP3 для сайта.

## Важно

Пять исходников не перезаписывать и не заменять обработанными версиями.
Панорамы пока не учитываются. После визуального сопоставления к каждому `track_id` можно будет добавить точку/координаты на панораме.

## Текущее ограничение

Таймкоды и конкретные места удаления пока не заполнены, поскольку для этого необходимо фактическое прослушивание пяти MP3. Заполнять их предположениями запрещено.
