## Принцип нарезки аудио

1. Сначала по тексту определить точные границы каждого смыслового фрагмента.
2. Затем найти тот же фрагмент в одном из пяти исходных MP3.
3. Сохранить исходник без изменений.
4. Создать raw-cut.
5. Обработать звук: шумоподавление, нормализация громкости, мягкая обработка пауз/оговорок без изменения смысла.
6. После проверки создать финальный трек.

## Следующий шаг

После визуального анализа двух панорам для каждого ID заполнить:

- точное положение точки на панораме;
- название физического экспоната;
- координаты/маркер;
- файл исходного аудио;
- начало и конец фрагмента;
- имя финального аудиофайла.
