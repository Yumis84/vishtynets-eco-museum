# Аудиогид — рабочие материалы

Эта папка содержит исходные и рабочие материалы для разработки аудиогида Виштынецкого эколого-исторического музея.

## Структура

- `source/text/` — исходные тексты экскурсии Алексея; не изменять без согласования.
- `source/audio/original/` — оригинальные записи экскурсии; исходники.
- `source/panoramas/hall-1/` — панорама первого зала и связанные материалы.
- `source/panoramas/hall-2/` — панорама второго зала и связанные материалы.
- `working/mapping/` — сопоставление точек панорам, экспонатов и фрагментов экскурсии.
- `working/transcripts/` — рабочие расшифровки и подготовленные текстовые фрагменты.

## Принцип работы

Сначала сопоставляем реальное расположение экспонатов на двух панорамах с полной экскурсией Алексея. Только после этого формируем окончательный набор аудиотреков.

Исходные материалы не заменяются рабочими версиями.
