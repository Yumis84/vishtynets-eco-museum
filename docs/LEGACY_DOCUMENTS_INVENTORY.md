## Provenance rules

- A document is marked **verified** only when its exact legacy target is confirmed.
- A listing on a legacy index is not proof that the file is still retrievable.
- A missing/broken binary is not treated as permission to substitute another document.
- Historical documents remain historical; current prices, contacts, opening rules and regulations require separate current verification.
