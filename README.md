# Виштынецкий экомузей

Современный mobile-first web-сервис Калининградского регионального общественного учреждения «Виштынецкий эколого-исторический музей» в Краснолесье.

## Статус

Начата отдельная музейная версия. Репозитории `guest-house-map` и `sauna-map-prototype` не изменяются.

## Архитектура

- `wystynez.ru` — legacy archive и источник музейного наследия;
- этот репозиторий — современная оболочка: карта, каталог, статьи, поиск и будущий AI-консультант;
- оригинальные legacy-медиа могут загружаться со старого сайта;
- оперативные данные (контакты, режим, цены) отделяются от архивных материалов и проверяются отдельно;
- гостевые дома не дублируются: раздел «Где остановиться» ведёт в `Yumis84/guest-house-map`.

## Дизайн

Новая дизайн-система использует цвета, извлечённые из оригинальных брендовых assets старого сайта:

- legacy blue: `#070AAB` — цвет оригинального текстового логотипа;
- leaf green: `#869A37` — доминирующий зелёный оригинального листа;
- основной фон: белый, как у исходных брендовых изображений.

Старая графическая вёрстка не копируется. Интерфейс строится как современный мобильный продукт.

## Уже реализовано в первом frontend-прототипе

- Leaflet + OpenStreetMap;
- полноэкранная мобильная карта;
- нижняя scroll-snap карусель;
- синхронизация карточки и активной метки;
- поиск и категории;
- геолокация «Вы здесь»;
- каталог объектов;
- избранное в localStorage;
- detail-card снизу;
- свайп карточки вниз для закрытия;
- горизонтальный свайп между объектами;
- независимый свайп фотогалереи;
- полноценный раздел «Статьи»;
- article reader с legacy-фотографиями и credits;
- интеграционная ссылка на отдельный сервис гостевых домов;
- UI будущего музейного AI-консультанта.

## Важно

Тексты первых карточек являются структурным seed из утверждённого проектного ТЗ. Полные оригинальные тексты legacy-статей будут переноситься без литературного переписывания по мере миграции.
